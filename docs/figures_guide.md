## 候補1　Dirac 量子ウォーク：「運動＝分解と再構成」（第9章）

### 計算の設定

1次元の格子（間隔 a）の上で、2成分スピノル ψ = (L, R) を次の2段で更新します（1ステップ＝時間 τ）。

1. **コイン（再構成）**：C(θ) = [[cosθ, −i sinθ], [−i sinθ, cosθ]]。左向き・右向きの成分を角度 θ で組み替える。
2. **シフト（移動）**：L を左へ、R を右へ1格子動かす。

運動量表示の分散関係は **cos ω = cos θ cos k**。ここから次が厳密に出ます。

| 量 | 式 | 意味 |
|---|---|---|
| 光速 | c = a/τ | 1ステップで1格子より遠くへは行けない |
| 静止エネルギー | ω(0) = θ/τ → mc² = ħθ/τ | 質量＝向きの組み替えの強さ |
| 群速度の上限 | v_max = c cos θ（k = π/2 で到達） | 同じ層の中では c を超えない |

**確立した物理**：以上は量子ウォークの標準的な結果（Bialynicki-Birula 1994 ほか）で、数値で検算済みです。
**モデルの仮定**：「霊界の層ごとに τ が違う」「層の乗り換えが符号化と復号で起きる」の2点。

### 図Q1　量子ウォークの時空図
> 原点に置いた状態が θ ごとにどう広がるか。確率は各時刻の最大値で規格化している。破線は光円錐 |x| = ct、実線は群速度の上限 c cosθ。

- 分布は破線の外に一切出ません。
- 分布の大部分は実線 c cosθ の内側にあります。θ が大きい（重い）ほど円錐が細くなります。
- **読み方**：光速は「1ステップで隣にしか書き込めない」という再構成規則の局所性から決まります。

### 図Q2　分散関係と群速度
> (a) 準エネルギー ω(k)。k = 0 の値が静止エネルギー θ。(b) 群速度。線は解析式、点は波束を実際に 800 ステップ動かして測った速度。

- 27点すべてで数値と解析式が一致しました（`results/representative/qw_group_velocity.csv`）。
- 上限 c cosθ は k = ±π/2 で到達します。

### 図Q3　厳密な光円錐と Lieb–Robinson の裾
> 時刻 200τ の確率分布（対数）。量子ウォーク（青）と、最大群速度を c に揃えた連続時間の格子ホッピング（橙）。

- **量子ウォーク**：光円錐の外の確率は**厳密に 0**（数値でも 0.0）。
- **連続時間のホッピング**：光円錐の外に確率 **2.3%** が漏れます。この裾は超指数的に減衰し、Lieb–Robinson 型の「実効的な」光円錐しか持ちません。
- **読み方**：離散的な「分解と再構成」は、光速を厳密な上限として持ちます。本文の「光速は再構成規則の局所性の性質」を最もはっきり示す図です。

### 図Q4　質量＝向きの反転の頻度（Zitterbewegung）
> (a) 初期スピノル (1, 0) の波束の平均位置の震え。(b) 震えの角振動数（数値）と 2θ（解析）。

- 12点での最大相対誤差は **0.57%** です。
- 震えの振動数は 2mc²/ħ で、質量が大きいほど速く向きが入れ替わります。ニュートンの霊言の「光のランプの点滅」の数理的な対応物です。

### 図Q5　2層ワープ：符号化 → 上位層での伝播 → 復号（代表値）

設定（代表値）：

| パラメータ | 値 |
|---|---|
| 光速比 cₙ/c₃ = r | 49（3次元 → 4次元の1段） |
| 上位層の cosθ* | 0.9 |
| 基底層の θ | 0.3 |
| 距離 | 4000 a |
| 船の大きさ σ | 30 a |

上位層は基底層の49倍の頻度で更新されます（τₙ = τ₃/49）。船は基底層で静止した波束です。

- **符号化**：運動量を π/2 だけずらし、固有基底（正エネルギー分枝）を対応させて上位層に写す。
- **復号**：目的地の窓の中の振幅を、逆の写像で基底層に戻す。

> (a) 上位層での確率密度。橙の線は基底層の光円錐（ほぼ垂直）、破線は上位層の光円錐。(b) 復号する時刻を変えたときに目的地で復元される確率。

| 結果 | 値 |
|---|---|
| 到着時刻（数値） | 90.65 τ₃ |
| T = d/(cₙ cosθ*)（式） | 90.70 τ₃（相対誤差 0.055%） |
| 実効速度（数値） | 44.12 c₃ |
| r cosθ*（式） | 44.1 c₃ |
| 同じ距離を基底層の光で進んだ場合 | 4000 τ₃ |
| 復元確率（内部状態まで書き換える符号化） | 1.0000 |
| 復元確率（位相だけを掛ける素朴な符号化） | **0.500** |

**読み取れること**

1. **第9章の式 v_warp = cₙ cos θ* は、実際の波動方程式の時間発展で成り立ちます。** 基底層の光円錐のはるか外側に、因果的な（上位層の光円錐の内側の）経路で到着します。
2. **符号化で内部状態（スピノル）を正しく書き換えないと、ちょうど半分が逆向きに進んで失われます。** 運動量だけを与えると、正と負のエネルギー分枝に等分されるためです。第9章の「認識は測定ではなく SWAP でなければならない」（最も弱い段）に、定量的な中身を与える結果です。「認識」は向きを決めるだけでは足りず、内部状態を行き先の層の固有状態に合わせる必要があります。

**モデルの仮定**：符号化と復号は理想的な（運動量表示で定義した）ユニタリ写像で、かかる時間 t_in・t_out はゼロとしています。これらの時間は層モデル（L1）で自由パラメータとして扱っています。

### 図Q6　到着時刻の距離依存と、船の大きさによる復元確率の低下
> (a) 到着時刻は cosθ* ごとに直線 T = d/(cₙ cosθ*) に乗る。(b) 船（波束）が小さいほど、上位層での広がり（3次の分散）で形が崩れ、目的地で復元できる割合が下がる。復号窓は ±3σ。

| σ | cosθ* | 距離 1000 a | 距離 8000 a |
|---|---|---|---|
| 3 a | 0.9 | 0.95 | 0.59 |
| 3 a | 0.5 | 0.75 | 0.32 |
| 12 a | 0.9・0.5 | ≥ 0.99 | ≥ 0.98 |

- **読み方**：局在した（細部まで決まった）物体ほど、上位層を長く通ると崩れやすくなります。cosθ* が低い（上位層で「重い」）ほど崩れが大きい。
- ここから「遠距離のワープでは、目的地での再構成に形の補正（設計図による復元）が要る」という要請が出てきます。付録D の「再物質化は設計図（古典情報）による」とつながる論点です。

### 図Q7　目的地の指定の精度
> 復号の位置と時刻をずらしたときの復元確率。復号窓 ±2σ。

- 時刻を合わせた場合、90% 以上を復元できる位置の誤差は **±0.7σ** 以内です。
- 位置を合わせた場合、許される時刻の誤差は **±0.47 τ₃** 以内です。
- 誤差は Δx = vΔt の方向には打ち消し合います。
- **読み方**：「目的地を霊的に確定する」（『神秘の法』）には、場所と時刻の組を、船の大きさ程度の精度で指定する必要があります。高次元バルクの研究ノートで述べた「律速は移動ではなく目的地の指定」を、数値で表したものです。

## 候補4　層ごとの速度上限モデル（49ⁿ 則）

### モデル（仮定）
cₙ = r^(n−3) c、v = cₙ cosθ*、T = t_in + d/v + t_out。代表値は r = 49、最上層 9次元、cosθ* = 1、t_in = t_out = 0 です。

**再現した研究ノートの数値**（tests で検算）：

| 量 | 値 |
|---|---|
| c₉ | 1.38×10¹⁰ c |
| プロキシマ | 9.68 ms |
| アンドロメダ | 1.58 時間（95 分） |
| 観測可能な宇宙の半径 | 3.36 年 |
| GW170817 で重力が4次元の層を通った場合の先着 | 1.27 億年 |

### 図L4　比 r を自由パラメータにしたときの整合性
> (a) 事例ごとに必要な層を r の関数として描く。(b) 最速の事例（メタトロン）を最上層までに収めるのに必要な最小の r を、cosθ* と最上層の次元ごとに示す。

**この解析の主な結論**

1. **すべての事例を9次元以内に収めるには r ≥ 66.2 が必要です**（cosθ* = 1 のとき）。認識力が cosθ* = 0.5 なら r ≥ 74 が必要になります。
2. ところが、経典の「9次元経由で光速の約100億倍」（Q9）は r⁶ ≈ 10¹⁰、つまり **r ≈ 46〜49** を指定します。
3. したがって **Q9 とアンドロメダ・メタトロンの事例は、49ⁿ 則の枠内では両立しません。** 両立させる道は次の三つです。
   - (i) 10次元の層を加える：最上層10次元なら r ≥ 36.5 で、r = 49 を含みます。
   - (ii) Q9 の「約100億倍」を下限と読む。
   - (iii) 二つの事例を別の機構（『メシアの法』の「霊速には限りがない」）で扱う。

   これは第9章 E-7 と「著者が判断を要する点」（10次元以上の層を加えるか）を定量化したものです。
4. r = 66.2 で計算し直すと（`figures/custom/r66_all_cases_in_9D/`）、ウンモ星はちょうど4次元、プレアデスは9次元、アンドロメダは9次元（上限の 0.52）、メタトロンは9次元の上限ちょうどに収まります。

## 注意（全図共通）

- 量子ウォークの図（Q1〜Q7）は、無次元の格子単位（a、τ）で書いています。実際の距離や時間への換算は、層モデル（L 系列）の式で行います。
- 49 という比は、研究ノートでも事例との整合による現象論的な当てはめ（E-6）です。図の「代表値」はこれを採用した場合の結果で、`custom` の図と L4 が r を動かした場合の結果です。
- シミュレーションが示すのは「モデルの仮定から何が導かれるか」であり、モデルそのものの証拠ではありません。
